# Scientific change log: V3 → V4

| Issue | V3 ambiguity | V4 resolution |
|---|---|---|
| Primary endpoint | Synthetic regression and future clinical plan in same report | Explicit prospective six-month WHO-5 single confirmatory endpoint |
| Sample size | Demonstration n=360 sometimes seen as clinical target | Baseline N=500, 400 completed with 20% attrition; exact sensitivity table |
| Target effect | ΔR² and partial R² could be conflated | Both differentiated; partial R² used in power calculation |
| Mixed methods | Culture terms broad and potentially stereotypical | Two brief descriptive items plus 24–30 interviews, four-cell purposive sampling |
| Burden | Treatment adherence optional and sometimes included | Fixed main battery 25 items; medication adherence no longer mandatory |
| Validity | Simulated alpha/ICC could be read as validation | Ordinal CFA, content validity and stability ICC proposed only for future real scale |
| Missingness | Demonstration-specific results | Preregistered MAR/MNAR sensitivity in future study |
| Ethics | No actual authorizations | Clear permission, recruitment, privacy and pre-registration gates |
| Research outputs | Simulation-based Results | Protocol and blank empirical reporting template; no invented patient results |

**Not changed:** V3 original synthetic demonstration is preserved separately; no synthetic estimate is now relabelled as clinical finding.
