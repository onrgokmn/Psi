# Psi · BDT Klinik Eğitim Kitabı

Bu dalda Eylül 2026 BDT eğitim belgelerinin konu başlıklarından geliştirilen özgün, gezilebilir bir klinik çalışma kitabı bulunmaktadır.

**Başlangıç:** [Kitabı tarayıcıda aç](index.html) (GitHub dosya görünümü) veya `index.html` dosyasını yerel tarayıcıda açın.

## Bölümler
- Psikiyatrik değerlendirme
- Terapötik ittifak ve motivasyon
- Bilişsel model
- Olgu formülasyonu
- Kurgusal görüşme
- Klinik uygulama kontrol listesi
- Kaynak ve etik sınırlar
